# Color-Code Audience Questions by Target Debater in Live Debates

* **Type:** UX / Usability Recommendation
* **Context:** Mobile live debate session — Audience Q&A / Comments feed
* **Current Behavior:** During a live debate, each of the two debaters is assigned a distinct visual color, while all incoming audience questions appear in the same neutral (white) style, making it difficult to quickly see whom a question is addressed to or whether it is a general comment.
* **Recommendation:** Highlight or color-code audience questions using the assigned color of the targeted debater (leaving general/unaddressed questions in the default neutral color) so speakers can immediately spot and read questions directed at them during a fast-moving live session.
