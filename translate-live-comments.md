# Add Translate Option for Live Session Comments

* **Type:** UX / Usability Recommendation
* **Context:** Mobile live session - Audience comments feed
* **Current Behavior:** During a live session, viewers can post comments in different languages, but there is no built-in translate button or option to translate foreign-language comments directly within the app.
* **Recommendation:** Add an inline "Translate" option on comments written in a language different from the user's app/device language so hosts and viewers can understand international comments instantly without leaving the live session.
