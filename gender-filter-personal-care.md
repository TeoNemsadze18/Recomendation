# Add Gender / Target Audience Filter in Personal Care Category

* **Type:** UX / Usability Recommendation
* **Context:** E-Commerce product catalog - Personal Care category
* **Current Behavior:** The Personal Care category mixes products for women and men without a gender/target-audience filter, making it harder for users to narrow down relevant items.
* **Recommendation:** Add a filter option (e.g., Women / Men / Unisex) in the Personal Care category so users can quickly filter products relevant to their needs.
